**This page** summarizes the entire worklog journey throughout an **8-week** internship (from June 2026 to July 2026). The content focuses on researching AWS cloud architectures, building and developing a Retrieval-Augmented Generation (RAG) system from a local environment to a cloud-based Serverless infrastructure, as well as conducting testing, optimization, and finalizing the internship report.

Below is a detailed summary of the work accomplished across the internship weeks:

**Week 1:** [Getting familiar with the working environment, orienting the RAG project, and exploring foundational concepts of cloud systems](1.1-week1/)

**Week 2:** [Exploring core AWS networking architectures (VPC, Subnet, Route Table, IGW, NAT Gateway) and establishing a secure 2-tier model with Amazon RDS/Aurora](1.2-week2/)

**Week 3:** [Building a local RAG prototype, integrating the BAAI/bge-m3 embedding model, connecting vector databases (Qdrant/pgvector), and integrating an LLM (Gemini)](1.3-week3/)

**Week 4:** [Initiating the architecture migration to AWS Serverless, handling Amazon Bedrock API authentication, and overcoming account restriction hurdles with AWS Support](1.4-week4/)

**Week 5:** [Deploying the system to AWS: Configuring Amazon Aurora Serverless with pgvector, migrating the Vectorize pipeline, and building the RAG API on AWS Lambda integrated with API Gateway](1.5-week5/)

**Week 6:** [Reviewing Backend/Lambda source code, connecting the complete End-to-End pipeline, resolving lingering bugs, and writing internal technical documentation](1.6-week6/)

**Week 7:** [Optimizing vector query performance, fine-tuning prompt instructions, and beginning to structure and draft the core chapters of the Internship Report](1.7-week7/)

**Week 8:** [Continuing comprehensive testing and debugging of the cloud-based RAG system, formatting, and finalizing the official Internship Report document](1.8-week8/)
